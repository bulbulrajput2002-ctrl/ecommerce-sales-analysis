# E-Commerce Sales & Customer Analytics

## Overview
End-to-end analysis of 100,000+ real orders from Olist, 
a Brazilian e-commerce platform (2016–2018), to uncover 
revenue trends, delivery performance issues, and customer segments.

## Key Findings
- Revenue grew 3x from early 2017 to mid 2018
- Credit card accounts for 78.4% of all revenue
- Northern states have 40%+ late delivery rates vs 10% for SP
- 75%+ of customers gave 4 or 5 star reviews
- RFM segmentation identified Champions, Loyal, At Risk customers

## Tools Used
Python · Pandas · NumPy · Matplotlib · Seaborn · SQL · Power BI

## Dataset
[Brazilian E-Commerce - Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)
100k+ orders · 9 tables · 2016–2018

## Project Structure
- ecommerce_analysis.ipynb — complete analysis notebook
- charts/ — all 10 generated visualisations

## How to Run
1. Download dataset from Kaggle link above
2. Place CSVs in /data folder
3. Run ecommerce_analysis.ipynb top to bottom
